Tuning

Settings

Thresholds are calibrated for isolated keywords and short utterances. Change one variable at a time.

Keyword matching

DISENT phonetic cosine.

Default 0.45. Lower finds more, but false positives rise.

Default 0.06. Requires the winning keyword to be clearly ahead.

Default 2.5 s. Longer clips are treated as arbitrary speech.

Speaker matching

ECAPA voiceprint cosine.

Default 0.08. Higher is stricter when two voices are close.

Default 1.00. Scales the duration-adaptive base threshold.

Default 1.5 s. Prevents a duplicate action from one utterance.

Segmentation

Silero VAD.

Default 0.50. Raise it in a noisy room.

Default 350 ms. Shorter blips are ignored.

Default 6.0 s. Force-finalizes if no VAD end arrives.
